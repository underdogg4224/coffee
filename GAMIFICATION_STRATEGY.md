# BeanzNeez Gamification Strategy

## 🎮 Why Gamification for a Deals Site?

**Problem:** Users visit once, grab a deal, never return
**Solution:** Reward repeated engagement with points, badges, levels, and prizes

**Benefits:**
- ✅ Increases return visits (30-40% boost typical)
- ✅ Builds habit formation
- ✅ Creates emotional connection to brand
- ✅ Generates user-generated content
- ✅ Encourages social sharing
- ✅ Justifies asking for email/account creation

---

## 🏆 Core Gamification System

### Bean Points System

**How Users Earn Points:**

| Action | Points | Frequency |
|--------|--------|-----------|
| **Account Creation** | 100 | One-time |
| **Email Verification** | 50 | One-time |
| **Daily Login** | 10 | Daily |
| **Using a Deal** (click through) | 25 | Per deal |
| **Rating a Deal** | 15 | Per rating |
| **Writing a Roaster Review** | 50 | Per review |
| **Submitting a Deal** | 100 | Per accepted deal |
| **Sharing on Social Media** | 20 | Per share |
| **Referring a Friend** | 200 | Per signup |
| **7-Day Login Streak** | 100 | Bonus |
| **30-Day Login Streak** | 500 | Bonus |
| **First Deal of the Day** | 25 | Daily bonus |
| **Trying 3 New Roasters/Month** | 150 | Monthly |
| **Leaving Helpful Review** (upvoted 10x) | 100 | Per review |

**Point Value:**
- 100 points = $1 in raffle entries
- OR use points to enter giveaways
- OR redeem for badges/status

### 🥇 User Levels & Status

**Progressive Ranking System:**

2. **☕ Coffee Explorer** (500-1,499 points)

4. **☕ Roast Master** (5,000-14,999 points)

   - Badge: "Master"
   - Feature in monthly "Member Spotlight"

5. **☕☕ Coffee Connoisseur** (15,000-49,999 points)

   - Badge: "Connoisseur"
   - Beta access to new features

**Visual Progress:**

## 🎁 Rewards & Redemption

### Point Redemption Options

**Option A: Raffle Entries**
- Spend points to enter monthly giveaway
- 100 points = 1 entry
- Unlimited entries allowed
- Prize: Coffee bundle ($100+ value)

**Option B: Direct Rewards**
- 5,000 points = $5 Amazon gift card
- 10,000 points = Featured deal slot (promote your favorite roaster)
- 25,000 points = Custom BeanzNeez merch (mug, shirt)
- 50,000 points = Private roaster tour (virtual or in-person)

**Option C: Status Perks**
- Keep accumulating for higher levels
- Better perks at each tier
- Exclusive access to features

**Best Strategy:** Encourage Option C (status) over cash redemption
- Keeps users engaged long-term
- Builds community
- Lower cost to us

## ⚠️ Gamification Pitfalls to Avoid

1. **Too Complex**: Keep it simple initially
2. **Too Grindy**: Don't make it feel like work
3. **Pay-to-Win**: Never sell points directly
4. **Unfair Advantages**: Level playing field
5. **Notification Spam**: Limit to important milestones
6. **Cheap Prizes**: Giveaways must have real value
7. **No Variety**: Rotate challenges regularly
8. **Stale Leaderboards**: Reset periodically
9. **Hidden Mechanics**: Be transparent
10. **Abandoning System**: Commit to ongoing support
